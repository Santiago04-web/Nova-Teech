# NOVA TEECH — Streetwear & Urban Fashion E-Commerce

Landing page e-commerce premium para la marca de ropa urbana **NOVA TEECH** (Cali, Colombia).

Diseño de alto impacto visual, minimalista, moderno y editorial, orientado a la conversión y experiencia de usuario fluida en desktop, tablet y mobile.

---

## ⚡ Identidad de Marca

- **Marca:** NOVA TEECH
- **Concepto:** Moda, estilo y actitud para todos los días.
- **Estética:** Streetwear de alta gama, editorial cinematográfico, siluetas contemporáneas y paleta oscura de alto contraste.
- **Paleta de Colores:**
  - Negro profundo (`#070708`)
  - Blanco (`#FFFFFF`)
  - Gris carbón & grafito (`#121316`, `#18191e`)

## 🚀 Características y Funcionalidades

1. **Navbar Adaptativo & Blur:**
   - Transparente sobre el Hero cinematográfico.
   - Pasa a fondo oscuro con desenfoque (`backdrop-blur`) al hacer scroll.
   - Navegación rápida (Inicio, Hombre, Mujer, Nuevos, Ofertas).
   - Acceso a búsqueda, cuenta y carrito con contador en tiempo real.
   - Menú lateral deslizante para dispositivos móviles.

2. **Hero Cinematográfico:**
   - Fotografía editorial con modelos urbanos y assets oficiales de Nova Teech.
   - Título contundente: *"ROPA QUE TE IDENTIFICA"*.
   - CTAs principales: *"COMPRAR AHORA"* y *"VER COLECCIÓN"*.
   - Indicadores de lanzamiento *"DROP 01 // 2026"*.

3. **Sección de Categorías Visuales:**
   - 4 categorías grandes: **Hombre**, **Mujer**, **Nueva Colección**, **Ofertas**.
   - Zoom suave en hover y aparición progresiva del botón de exploración.
   - Filtrado dinámico automático en el catálogo de productos al hacer clic.

4. **Catálogo de Productos Destacados ("LO MÁS BUSCADO"):**
   - Grid adaptable (2 columnas en móvil, 4 en desktop).
   - Doble imagen interactiva en hover (segunda vista / detalle).
   - Selector visual de colores con etiquetas descriptivas.
   - Botón directo de *"AGREGAR AL CARRITO"* con feedback animado.
   - Botón de lista de deseos (favoritos) reactivo.
   - Modal de Vista Rápida (*Quick View*) con selección de talla (S, M, L, XL), especificaciones textiles (450 GSM, 100% algodón colombiano peinado) y galería de fotos.

5. **Banner Editorial de Nueva Colección:**
   - Sección de ancho completo con estética de campaña de moda.
   - *"NUEVA COLECCIÓN // ELEVA TU ESTILO"*.

6. **Garantías y Beneficios Comerciales:**
   - 🚚 Envíos a todo Colombia.
   - 🔒 Pagos seguros con pasarelas certificadas.
   - ↩ Cambios y devoluciones fáciles.
   - ✦ Calidad certificada Nova Teech.

7. **Comunidad e Instagram Lookbook:**
   - Galería de estilos urbanos con interacción hover y botón directo a `@novateech`.

8. **Newsletter VIP:**
   - *"ENTRA AL UNIVERSO NOVA TEECH"*.
   - Validación de email y entrega de cupón promocional del 10% OFF.

9. **Carrito Deslizante y Checkout por WhatsApp:**
   - Cajón lateral (*slide-over drawer*) con cálculo de subtotal en pesos colombianos (COP).
   - Barra de progreso para envío gratis.
   - Generador automático de pedidos formateados para WhatsApp con un solo clic.

10. **Botón Flotante de WhatsApp:**
    - Acceso directo a atención al cliente en la esquina inferior derecha.

11. **SEO & Verificación de Dominio:**

## 💻 Instalación y Desarrollo Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/Santiago04-web/Nova-Teech.git
cd Nova-Teech

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev

# 4. Construir para producción
npm run build

# 5. Previsualizar compilación
npm run preview
```
